## 5. Proposed PAA rules and QC gate (needs Divit's approval; replaces the current F4 logic)
Principle: a question is rejected unless it proves it belongs on the page (today's F4 admits any question sharing one specific word). Runs on all existing FAQs too, since all were sourced from DataForSEO. Needs one real AlsoAsked export to build the parser against its format.

| ID | Rule |
|---|---|
| PA1 | Source: AlsoAsked only (US, English). Each item records tool, query, depth, parent question, fetch date and original wording. DataForSEO PAA is no longer an FAQ source. |
| PA2 | Depth: level 1 eligible; level 2 only if its parent passed; level 3+ never required, allowed only with a written reason. |
| PA3 | Entity match: the full head phrase ("registration form") or an approved per-page synonym; a single shared word never qualifies. |
| PA4 | Wrong-sense blocklist: global (vehicle, DMV, exam, UPSC, allowance, IRDAI, ...) plus a per-page skip list with logged reasons. |
| PA5 | US audience: non-US agencies, laws, exams or benefits rejected. |
| PA6 | Asker test: builder/operator, respondent or unrelated. Unrelated blocked; at most 2 respondent questions, only if answerable without advice. |
| PA7 | Advice risk: legal, medical, tax or financial "should I / do I need / am I eligible" blocked; definitional legal questions only with a primary (.gov or statute) source. |
| PA8 | Third-party brands: at most 1 per page, only library competitors, neutral answer; retailer and gift brands blocked. |
| PA9 | No same-intent duplicates within a page. |
| PA10 | One page per question per hub; generic questions belong to the hub page. |
| PA11 | Shortfall: fill from secondaries, never from rejected PAA; under 8 on-topic questions parks the page. Nothing forced in. |
| PA12 | Kept: exactly 10 items, definition first, how-to-build second with the hub link, at least 6 secondaries, answer-first. |
| PA13 | Human gate: one page listing every page's 10 questions for Divit to skim before any publish. |
